# ちんだみ - 三線チューナー

沖縄の伝統楽器「三線（さんしん）」の調弦をサポートするAndroidアプリです。

スマートフォンのマイクから音を取得し、リアルタイムで音程を解析して、調弦をサポートします。

## 主な機能

- マイクによるリアルタイム音程検出
- 本調子・二揚げ・三下げ・一二揚げに対応
- 男絃・中絃・女絃の音程表示
- 音程の高低を針で視覚的に表示
- 基準音・A4周波数の調整

## 使い方

1. アプリを起動します。
2. 「マイクを開始」を押してマイクの使用を許可します。
3. 調弦（本調子・二揚げ・三下げ・一二揚げ）を選択します。
4. 男絃の基準音を選択します。
5. 三線の各絃を鳴らし、針を確認しながら音程を合わせます。

## 調弦設定

本調子の男絃を基準とした音程関係です。

| 調弦 | 男絃 | 中絃 | 女絃 |
|---|---|---|---|
| 本調子 | 0 | +5 | +12 |
| 二揚げ | 0 | +7 | +12 |
| 三下げ | 0 | +5 | +10 |
| 一二揚げ | +2 | +7 | +12 |

※ 数字は半音単位です。一二揚げについては、アプリ内の基準音の扱いを確認中です。

## 使用技術

- HTML / CSS
- JavaScript
- Web Audio API
- YINアルゴリズム（音程検出）
- Capacitor
- Android Studio

## 開発環境での起動方法

Node.jsとAndroid Studioを使用します。

プロジェクトのルートディレクトリで以下を実行します。

1. `npm install`
2. `npx cap sync android`
3. `npx cap open android`

Android Studioからアプリをビルドし、Android端末で実行します。

## 注意事項

- マイクの使用許可が必要です。
- ブラウザ版でマイクを利用する場合は、原則HTTPSまたはlocalhost環境が必要です。
